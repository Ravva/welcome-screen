# Product Context

## Problem

Компании нужен технологичный и быстрый способ приветствовать сотрудников и фиксировать события прохода через входную зону без использования внешних облачных сервисов.

## Users

- Сотрудники — видят персональное приветствие при входе.
- Гости/неизвестные лица — видят нейтральное приветствие.
- Администратор — управляет сотрудниками, фотографиями, ролями, настройками и логами.
- Менеджер/оператор — просматривает журнал событий и управляет частью данных в рамках роли.
- Технический специалист — следит за состоянием системы через `/health` и логи.

## Product Value

- Повышение технологического имиджа компании.
- Улучшение пользовательского опыта на входе.
- Локальная обработка биометрических данных.
- Быстрое отображение приветствия на ТВ-экране.
- Журнал событий для последующего анализа.

## Key Scenarios

1. Распознанный сотрудник проходит через рамку металлоискателя, система показывает персональную карточку.
2. Неизвестное лицо проходит через входную зону, система показывает нейтральное приветствие, логирует событие и сохраняет фото.
3. Если обнаружено несколько лиц, система логирует `multiple_faces` и не показывает персональное приветствие.

## Deferred Decisions

- Сроки хранения фото неизвестных лиц и snapshot-изображений.
- Юридический регламент обработки биометрических данных.
- Канал уведомлений администратора о неизвестных лицах.
- Стратегия переполнения очереди приветствий: FIFO или `latest wins`.
